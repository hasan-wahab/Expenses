## App name

**Home Expense Tracker**  
Optional brand line: Zenith Finance

---

## One-line pitch

A Pakistan-focused app to manage expenses for multiple properties — homes, shops, apartments — all in **PKR**.

---

## What the app does

The user adds multiple properties. On each property they log expenses (gas, electric, water, food, custom categories) and can attach an optional receipt photo. They can view spending with charts, then export a PDF property report. Accounts are created with email, verified once, and later unlocked faster with fingerprint. Data syncs to the cloud.

---

## Target user

Pakistani homeowners, landlords, and small business owners who manage one or more properties (home / apartment / shop / office) and want clear expense tracking in PKR.

---

## Key features (show in logo / screenshots)

1. Multi-property tracking — many properties in one place  
2. Expense logging — categories + optional receipt  
3. PKR only — Pakistani Rupees, not dollars  
4. Summary / charts — category breakdown and spending overview  
5. PDF property report — share or print  
6. Secure account — email verify + fingerprint unlock  
7. Cloud sync — data stays with the user across devices

## Play Store copy

### Short description

Track property expenses in PKR — multi-property, charts & PDF reports.

### Full description

Home Expense Tracker helps you manage spending across your properties — homes, apartments, shops, and more — all in Pakistani Rupees (PKR).

Add each property, log everyday expenses like gas, electricity, water, food, and custom categories, and attach receipts when needed. View clear charts and category breakdowns, then export a clean PDF property report to share or keep for your records.

Create an account with email verification, sync your data securely, and unlock faster next time with fingerprint login.

Simple. Organized. Built for property expense tracking in Pakistan.

## User journey (for understanding flows)

1. Onboarding (first launch)  
2. Sign up → email verify  
3. Add first property  
4. Log expenses under that property  
5. Open summary / charts  
6. Export PDF from settings  
7. Optional: enable fingerprint
